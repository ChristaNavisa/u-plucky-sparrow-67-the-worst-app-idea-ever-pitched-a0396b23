A one-sentence pitch for the worst, most useless app imaginable — an entry for the
[make.fun bounty "The Worst App Idea Ever Pitched"](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).

`main.ts` writes a single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).

The pitch: FridgeRun — a premium delivery service for moving your own leftovers one shelf down, because bending down is a burden no modern family should face alone.
